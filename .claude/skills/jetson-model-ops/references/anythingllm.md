# AnythingLLM on the Jetson (optional)

Moved out of the main procedure. Assumes Docker and a working Ollama.

7. **AnythingLLM** (Docker, arm64 image `mintplexlabs/anythingllm`): bind the UI to a private (for example VPN) address only, `--memory 1500m`, `--cap-add SYS_ADMIN`, `--restart unless-stopped`, volumes for `storage/` and a `.env` file, `--add-host=host.docker.internal:host-gateway`, env `LLM_PROVIDER=ollama`, `OLLAMA_BASE_PATH=http://host.docker.internal:11434`, a small chat model, and `EMBEDDING_ENGINE=ollama` with an embedding model. Verify `docker ps` health and an HTTP 200 from the UI.
   - **Set Ollama to one loaded model** (`OLLAMA_MAX_LOADED_MODELS=1`, `OLLAMA_NUM_PARALLEL=1` in `/etc/systemd/system/ollama.service.d/override.conf`, then `daemon-reload` and restart). A RAG query loads the embedder and the chat model together; with a 3.5 GB chat model that left about 180 MB free and the runner crashed (`model runner has unexpectedly stopped`). With one model at a time free memory stayed near 1.5 GB at the cost of a few seconds per query.
   - **Changing the chat model means changing two places**: the bind-mounted `.env` (the UI writes its choice there, so it can silently differ from the `-e` flags the container was started with) and the `-e OLLAMA_MODEL_PREF` flag; then `docker rm` and re-run (storage survives). Model names with `hf.co/...:QUANT` are valid values.
   - **End-to-end test without the UI**: with the container stopped, insert a temporary row into `storage/anythingllm.db` (`api_keys(secret,name)`), restart, then use `/api/v1/workspace/new`, `/document/raw-text`, `/workspace/<slug>/update-embeddings`, `/workspace/<slug>/chat` (`mode: query`). Ask questions whose answers are in the document, and score them by reading the answers: a substring check passed a wrong answer. Afterwards delete the workspace via the API, delete the key row and key file, and delete the raw document JSON under `storage/documents/custom-documents/` by hand (the remove-document endpoint returned a web page). Leave existing workspaces alone.
